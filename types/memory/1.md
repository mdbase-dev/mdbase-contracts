# Memory

One thing an assistant should remember about you, at `Memories/<name>.md`.
The note's body is the memory; its frontmatter is the index assistants read
first.

```markdown
---
description: Prefers metric units and 24-hour times in every answer
kind: feedback
by: Claude
---
Use kilometres, kilograms, Celsius and 24-hour times.

Why: they find imperial units and am/pm slow to read.
How to apply: convert any figures a source gives in other units.
```

Assistants that reach this collection through mdbase recall by listing each
memory's name, description and kind, then reading the few that matter. When
they learn something worth keeping, they update the memory on that subject or
add a new one. You can read, correct or delete any memory here yourself.

This type belongs to your collection once installed. Apps find memories
through the `mdbase.memory` contract, not through this folder, so you can move
them by changing both `match.path_glob` and `collection.path.pattern`, or add
fields of your own.
